# Panther Hotel

A simple hotel reservation website built with Python and Flask. Users can book a room by entering their name, check-in/check-out dates, and room type. Reservations are stored in a SQLite database and can be viewed through a manager page.

## Features
- Welcome page with booking and manager access
- Room reservation form
- Booking confirmation page
- Manager view to see all reservations

## How to Run
1. Create and activate a virtual environment: `python3 -m venv venv` then `source venv/bin/activate`
2. Install Flask: `pip install flask`
3. Run the app: `python app.py`
4. Open http://127.0.0.1:5000
